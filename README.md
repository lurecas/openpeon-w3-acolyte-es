# OpenPeon Warcraft III Acolyte (ES)

This repository contains a sound pack for the [Open Peon initiative](https://openpeon.com/).

It provides a **Warcraft III** voice package for the **Undead Acolyte** in **Spanish**.

## Contents

- `openpeon.json`: package metadata and sound mapping
- `sounds/`: WAV files used by the pack

## Package Details

- Name: `acolyte_es`
- Display name: `Acólito Muertos Vivientes Warcraft III (ES)`
- Language: `es`
- Version: `1.0.0`
- License: `CC-BY-NC-4.0`

## About Open Peon

Open Peon is an initiative for reusable voice/sound packs for developer workflows.

Learn more at: <https://openpeon.com/>
